## 1. 阶段分解（WBS）

### S0 — 环境准备与工程骨架 ✅进行中
- JDK 17 / Android platform-34 / Gradle 8.13 缓存复用
- 工程目录、Gradle 脚本、Manifest、主题（E-Ink 纯黑白、禁用窗口动画）
- 基础资源：`dimens`（600×800：图标 36dp/热区 48dp；sw600dp：40dp/56dp）
- **产出**：可编译 APK 骨架

### P0-A — EAL 设备抽象层 + 存储 + 编码
| 编号 | 任务 | 需求 ID | 验收 |
|---|---|---|---|
| A1 | `DeviceProfileDetector`（SoC 双档 + RAM 三档 + 配置库匹配 + 手动覆盖） | F17/F20 | 已知设备 100% 识别，未知走 fallback |
| A2 | `readit_device_profiles.json` + 手动导入 | F18 | 内置 + 导入生效 |
| A3 | `CapabilityTier` 六档组合 + `RenderStrategy` | F20 | 六档策略正确切换 |
| A4 | `RefreshModeManager`（AUTO/QUALITY/FAST/REGAL/SYSTEM，Onyx EPD 反射） | F16 | 已适配设备残影可控，未适配提供设置 |
| A5 | `StorageManager` 导入原子性（临时文件→校验→重命名→回滚） | F14 | 中断/失败无残留、无半文件 |
| A6 | `EncodingDetector`（juniversalchardet + BOM 短路 + 手动选择） | F15 | 基准语料 >95% |

### P0-B — WebDAV + TLS 1.2
| 编号 | 任务 | 需求 ID | 验收 |
|---|---|---|---|
| B1 | `Tls12SocketFactory`（API 19 强制 TLS 1.2，禁 SSLv3/TLS1.0/1.1） | R21 | API 19 连通性回归通过 |
| B2 | OkHttp 3.12.13 + ConnectionSpec 安全套件 + UA `ReadIt-Sync-Agent/1.0` | F13 | 握手成功 |
| B3 | ETag 优先，无 ETag 用 Last-Modified + 客户端版本号兜底 | F13/R19 | 不静默覆盖 |

### P0-C — 三项技术门禁（冻结前必须完成）
| 编号 | 门禁 | 结论口径 |
|---|---|---|
| C1 | PdfBox-Android 在 A33 级 + 1GB 上的性能/内存基准 | 单页提取耗时/峰值内存，决定 PDF 兜底走文本还是缩略图 |
| C2 | 内置 OOXML 子集解析器原型（`[Content_Types].xml` / `document.xml` / `_rels` / `numbering.xml` / `media`） | 复杂元素降级不崩溃 |
| C3 | WebView 能力分级判定（API 26+ `getCurrentWebViewPackage`；API 19-25 UA + JS 特性探测） | 通过→epub.js；不通过→文本抽取降级 |

### P1 — TXT 渲染 + 输入 + 600×800 适配
- `TxtCanvasView` 自绘 + 懒分页（F01，首屏 <4s）
- `ChapterDetector` 识别率 >90%，无章节按长度分页（F02）
- `InputMapper`：触控左/中/右分区 + 实体键 + **按键学习向导**（F11/F19）
- 字号/行距/边距实时预览 + 持久化（F12）；进度保存恢复（F09）
- 600×800 UI 完整适配（F21）；TalkBack 控件可读

### P2 — EPUB + 目录 ✅完成（代码闭环，10/10 用例通过；首章 <8s / 跳转 <500ms 待真机）
- epub.js v0.3.88 内置 `assets/readit_epub/` + `EpubWebView` + `ReadItBridge`（F03）
- `EpubParser`：container.xml → OPF → EPUB3 nav → EPUB2 NCX → spine 兜底；DRM 识别
- 降级路径：`EpubTextExtractor` 文本抽取 + TxtCanvasView（保留目录/章节，进度 = 章节 + 字符偏移）
- 目录侧滑 90vw，统一 `TocEntry` 模型；epub.js 路径跳转走 spine 下标（F10）
- 详见 `docs/P2 EPUB与目录交付说明.md`

### P3 — DOCX + PDF + 同步 ✅完成（代码闭环，74/74 用例通过；时限类指标待真机）
- `DocxConvertService` 独立进程 `com.readit.eink:converter` + 子集渲染 + 降级提示（F04）
  - `DocxConverter` 服务优先、主进程内联兜底；产物落盘走文件而非 Binder Bundle
  - `DocxHtmlToc` 注入 `h1~h6` 锚点 + 抽目录 + 媒体路径相对化（纯 JVM 可测）
- `PdfRenderView`（PdfiumAndroid 1.9.0）+ 裁边（F05/F07）+ `getTableOfContents` 目录（F06）
  - 后台线程渲染 + `renderSeq` 丢弃过期页；`PdfCropper.decide()` 几何判定纯函数化
  - Pdfium 打不开时退到 PdfBox 文本档（`PDF_TEXT`）
- `PdfTextExtractor.detectScan()`：3 页采样（首末页必中）+ 字符数 × 整页大图双信号 + 阈值可调 + 强制导入（F08）
- WebDAV 双向同步（F13）：`SyncDecider` 决策纯函数化，ETag → Last-Modified → 体积兜底链，冲突不写入
- 详见 `docs/P3 DOCX_PDF_同步交付说明.md`

### P4 — 打磨 + 基准 + Beta
- 真机矩阵：兜底 SoC+1GB / 标准 SoC+2GB / **KY-01L（600×480，ADB 侧载）**
- 四格式性能基准（双 SoC 档）；540×960 / 600×480 极限 UI 回归
- 引导 + 设置 + 备份；社区 Beta + 设备收集工具
